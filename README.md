# BK专属笔记

BK专属笔记是一个功能丰富的本地存储笔记应用程序，允许您创建、编辑和搜索您的个人笔记。支持插入图片、代码、GIF和视频链接，并可将笔记备份到GitHub。

## 功能特点

- 创建和编辑笔记
- 实时搜索功能
- 支持插入图片、代码块、GIF和视频链接
- 本地浏览器存储（数据保存在您的设备上）
- 可将笔记备份到GitHub仓库
- 删除笔记前需要二次确认，防止误删
- 支持与GitHub双向同步（上传、下载、合并）
- 响应式设计，支持移动设备
- 简洁美观的用户界面
- 分离的编辑页面，提供更佳的编辑体验

## 如何使用

### 基础功能
1. 打开 `index.html` 文件即可在浏览器中使用
2. 点击"新建笔记"按钮创建新的笔记
3. 点击任意笔记进入专门的编辑页面进行详细编辑
4. 使用顶部的搜索框查找特定笔记
5. 点击"删除"按钮移除不需要的笔记（删除前会有二次确认）

### 高级功能
#### 插入图片和GIF
在笔记内容中使用Markdown语法：
```
![描述文字](图片URL)
```

或者在编辑页面使用工具栏按钮。

#### 插入代码
使用代码块语法：
```
\```javascript
console.log('Hello World');
\```
```

或者在编辑页面使用工具栏按钮。

#### 插入视频
使用链接语法：
```
[视频标题](视频链接)
```

### 同步到GitHub
点击"同步到GitHub"按钮，您可以选择三种同步方式：
1. **上传本地笔记到GitHub**：将您当前本地的所有笔记上传到指定的GitHub仓库
2. **从GitHub下载笔记**：从GitHub仓库下载笔记并替换本地笔记
3. **合并本地与GitHub笔记**：将本地笔记与GitHub上的笔记合并，保留所有笔记并去重

操作步骤：
1. 输入您的GitHub Personal Access Token
2. 输入您的GitHub用户名和仓库名称
3. 选择合适的同步选项
4. 点击相应按钮完成同步

## 技术栈

- HTML5
- CSS3
- JavaScript (ES6)
- Web Storage API (localStorage)
- GitHub REST API

## 存储说明

所有笔记数据都存储在浏览器的本地存储中，不会发送到任何服务器。清除浏览器数据可能会导致笔记丢失，请定期使用"同步到GitHub"功能备份重要数据。
