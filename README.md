# BKnote - 在线笔记工具

BKnote 是一个简单易用的本地存储笔记应用程序，允许您创建、编辑和搜索您的个人笔记。

## 功能特点

- 创建和编辑笔记
- 实时搜索功能
- 本地浏览器存储（数据保存在您的设备上）
- 响应式设计，支持移动设备
- 简洁美观的用户界面

## 如何使用

1. 打开 `index.html` 文件即可在浏览器中使用
2. 点击"新建笔记"按钮创建新的笔记
3. 点击笔记的标题或内容区域进行编辑
4. 使用顶部的搜索框查找特定笔记
5. 点击"删除"按钮移除不需要的笔记

## 技术栈

- HTML5
- CSS3
- JavaScript (ES6)
- Web Storage API (localStorage)

## 存储说明

所有笔记数据都存储在浏览器的本地存储中，不会发送到任何服务器。清除浏览器数据可能会导致笔记丢失，请定期备份重要数据。

## 响应式设计

该应用针对桌面和移动设备进行了优化，可以在各种屏幕尺寸上良好显示。
